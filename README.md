# Andrew Chuang 承翰

Personal site. Four tellings of the same page, plus a foyer.

- `/` foyer
- `/film` stills
- `/book` sewn copy
- `/story` one letter
- `/taiwan` a ticketed road
- `/diet` info diet cabinet (static snapshot)

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy `dist/` to Vercel. Client routes rewrite to `index.html`.
